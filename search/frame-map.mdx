**Beta**

Frame Map places indexed video frames on a two-dimensional canvas. Visually similar frames appear near one another, so you can browse themes and outliers without starting with a search query.

## In the app

Frame Map is available at [platform.pureframe.ai/framemap](https://platform.pureframe.ai/framemap).

- **Hover** a dot for a frame preview and video name
- **Click** a dot to pin it to the preview strip at the bottom
- **Double-click** to open the video at that timestamp
- **Lasso select** a region to inspect multiple frames at once
- **Click a cluster** in the sidebar to pin every frame in that cluster at once
- **Filter by collection** using the left panel

Related frames appear in labeled clusters such as outdoor scenes or whiteboard footage. Frames that do not belong to a clear group appear as uncategorized. Larger and more varied libraries tend to produce more useful groupings.

## API access

```bash
curl "https://api.pureframe.ai/v1/framemap?collection_id=col_abc123" \
  -H "Authorization: Bearer pf_..."
```

```json
{
  "data": {
    "frames": [
      { "id": "frm_1", "x": 12.4, "y": -8.1, "video_id": "vid_abc", "collection_id": "col_abc123", "timestamp_start": 42.5, "thumbnail_url": "https://...", "cluster_id": 3 }
    ],
    "clusters": [
      { "id": 3, "label": "Whiteboard", "color": "#4f46e5", "frame_count": 128, "video_count": 6 }
    ],
    "total_frames": 4211,
    "total_videos": 18,
    "total_collections": 1
  }
}
```

Omit `collection_id` to request a map for the account. Set `force=true` to request a refreshed map after adding or removing substantial content.

The Python SDK exposes this as `client.frame_map.get_framemap(...)`.
