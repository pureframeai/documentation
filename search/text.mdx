---
title: Text Search
description: Find moments using a natural language description.
---

Send a plain-language description in `query`. By default, Pureframe AI searches both visual and spoken content.

```bash
curl -X POST https://api.pureframe.ai/v1/search \
  -H "Authorization: Bearer pf_..." \
  -F "query=person waving at the camera" \
  -F "collection_id=col_abc123"
```

`collection_id` is required for text-only queries. Image search can search across your account without a collection filter.

## How matching works

A text query can match:

- Visual content that is conceptually similar to the description
- Spoken content that contains relevant wording
- Scene labels and on-screen text, when available

See [Combined queries](/search/combined-queries) to restrict the active signals.

## Natural language queries

Set `natural_language=true` for longer, conversational requests such as `find the moment someone mentions the annual contract`.

```bash
curl -X POST https://api.pureframe.ai/v1/search \
  -H "Authorization: Bearer pf_..." \
  -F "query=find the moment someone mentions the annual contract" \
  -F "natural_language=true" \
  -F "collection_id=col_abc123"
```

Natural-language search is available on paid plans. Set the flag explicitly when you call the REST API or an SDK.

## Improve weak results

If a query returns no useful results:

1. Confirm that the video status is `done`.
2. Confirm that `collection_id` identifies the intended collection.
3. Use concrete visual details or wording likely to appear in speech.
4. Try one search mode at a time to identify which signal works best.
5. Use `natural_language=true` for a longer request.
