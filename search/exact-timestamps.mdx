---
title: Timestamp Precision
description: Interpret segment timestamps and seek to a matched moment.
---

Each segment includes `timestamp_start` and `timestamp_end` in seconds. These values locate the match in the source video, but they are not frame-accurate edit points.

## Frame and scene segments

Treat `frame` and `scene` timestamps as navigation points near the relevant visual content. For playback, seek slightly before `timestamp_start` so the viewer has context.

If your workflow requires frame-accurate boundaries, verify the match against the source video and calculate the final in and out points in your editing pipeline.

## Transcript segments

Transcript timestamps locate a matching passage of speech. Include a small playback buffer before the start time to avoid cutting off the beginning of a sentence.

## Using timestamps to seek video

`video_url` points to the source video, not a pre-trimmed clip. Append a media fragment or use your player's seek API:

```html
<video src="{video_url}#t={timestamp_start}"></video>
```

Browser support for media fragments varies by format and server behavior. Use the player API when you need consistent seeking.

Pureframe AI does not return a separately trimmed media file. Create one in your own media workflow when you need a downloadable clip.
