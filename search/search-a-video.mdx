---
title: Search a Video
description: Working with one specific video once you've found it.
---

The search endpoint does not accept `video_id` as a scope. Text searches run within a collection, while image searches can also run across your account. See [Search a collection](/search/search-a-collection).

After you obtain a `video_id` from a search result or collection listing, fetch that video directly:

```bash
curl https://api.pureframe.ai/v1/videos/vid_def456 \
  -H "Authorization: Bearer pf_..."
```

```json
{
  "data": {
    "id": "vid_def456",
    "filename": "footage.mp4",
    "collection_id": "col_abc123",
    "status": "done",
    "duration_secs": 612.4,
    "playback_url": "https://...",
    "thumbnail_url": "https://...",
    "segments_count": 34
  }
}
```

`playback_url` is a presigned URL valid for about an hour: fetch a fresh one each time you need to play the video rather than caching it. See [Metadata](/video-processing/metadata) for every field on the video object.

## If you want "more like this, in this video"

If a search already returned segments from the video you care about, use each segment's `video_id` to filter the response client-side instead of making another request. To find visually similar moments across the same collection, submit one of the video's frame thumbnails as a reference image. See [Image search](/search/image).

## Deleting a video

```bash
curl -X DELETE https://api.pureframe.ai/v1/videos/vid_def456 \
  -H "Authorization: Bearer pf_..."
```

Permanently removes the video file, all frame data, and indexed segments. Returns `204 No Content`. This cannot be undone.
