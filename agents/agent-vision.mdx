Agent vision lets a compatible AI client search your video library, retrieve video details, and inspect matched frames.

## How it works

When an agent calls `search_videos`, results include `thumbnail_base64`, a base64-encoded JPEG of the matched frame. A vision-capable model can use this image without fetching a separate URL:

1. The agent searches for a video segment.
2. Pureframe AI returns matching metadata and a frame image.
3. The model uses the returned evidence to answer the request.

The model may still make mistakes. Ask it to cite the source video and timestamp, and let users open the returned playback URL for verification.

## Two ways to connect

**MCP**: use an MCP-compatible client such as Claude, Cursor, VS Code, Codex, or OpenCode. See [MCP overview](/agents/mcp-overview) and [Connect an agent](/agents/connect-an-agent).

**Direct HTTP or function calling**: fetch the OpenAI-compatible tool schema when you are building your own agent integration:

```python
import httpx

BASE = "https://api.pureframe.ai"
HEADERS = {"Authorization": "Bearer pf_..."}

# Get the tool schema (OpenAI format)
schema = httpx.get(f"{BASE}/v1/agent/schema.json", headers=HEADERS).json()

# Call a tool
result = httpx.post(f"{BASE}/v1/agent/call", headers=HEADERS, json={
    "tool": "search_videos",
    "input": {
        "query": "presenter pointing at a chart",
        "collection_id": "col_abc123",
        "limit": 5
    }
}).json()
```

Pass `schema` to the tool configuration supported by your model provider.

## Search and inspect a frame with Claude

Set `ANTHROPIC_MODEL` to a vision-capable model available to your Anthropic account.

```python
import os

import anthropic
import httpx

client = anthropic.Anthropic()
pf = {"Authorization": "Bearer pf_..."}

# Search for a moment
clips = httpx.post("https://api.pureframe.ai/v1/agent/call",
    headers=pf,
    json={"tool": "search_videos", "input": {"query": "whiteboard diagram", "limit": 1}}
).json()["data"]

# Pass the matched frame directly to Claude
frame_b64 = clips[0]["thumbnail_base64"]

response = client.messages.create(
    model=os.environ["ANTHROPIC_MODEL"],
    max_tokens=1024,
    messages=[{
        "role": "user",
        "content": [
            {"type": "image", "source": {"type": "base64", "media_type": "image/jpeg", "data": frame_b64}},
            {"type": "text", "text": "What's written on the whiteboard?"}
        ]
    }]
)
print(response.content[0].text)
```

## Tool response fields

`search_videos` returns a list of clips. Each clip:

| Field | Description |
|-------|-------------|
| `video_id` | ID of the source video |
| `filename` | Original filename |
| `start_secs` / `end_secs` | Clip boundaries in seconds |
| `relevance_score` | Relevance from 0 to 1 |
| `text_snippet` | Transcribed speech in this clip, if available |
| `clip_url` | Presigned URL to stream the video (valid ~1 hour) |
| `thumbnail_url` | Presigned URL to the matched frame |
| `thumbnail_base64` | Base64 JPEG for direct use with vision models |

Use these fields to make an answer verifiable. See [Source-backed results](/agents/source-backed-results).
